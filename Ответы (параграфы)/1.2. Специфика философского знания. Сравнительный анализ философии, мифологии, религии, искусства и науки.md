
# 1. В чём специфика философии

Философия влияет на человека:

- **напрямую** → развивает мышление, анализ, самостоятельность
- **косвенно** → через науку, религию, искусство

формирует **[[мировоззрение]] и ценности**

---

# 2. Сравнение философии с другими формами культуры

## 1. По предмету (что изучает)

- **Философия** → всё в целом (мир, человек, бытие)
- **Мифология** → мир через фантазии и опыт
- **Религия** → Бог и священное
- **Наука** → законы природы
- **Искусство** → мир в образах

философия = **самое общее и целостное знание**

## 2. По характеру знания

- **Философия** → рациональное (логика)
- **Мифология** → фантазия
- **Религия** → вера + разум
- **Наука** → логика + опыт
- **Искусство** → эмоции

## 3. По языку

- **Философия** → понятия, категории
- **Мифология** → образы
- **Религия** → символы
- **Наука** → формулы, термины
- **Искусство** → метафоры

## 4. По тексту и автору

- **Философия** → авторские идеи
- **Мифология** → анонимные мифы
- **Религия** → священные тексты
- **Наука** → объективные законы
- **Искусство** → авторское творчество

## 5. По типу мышления (рефлексии)

- **Философия** → критика и размышление
- **Мифология** → без критики
- **Религия** → догмы
- **Наука** → анализ и проверка
- **Искусство** → ассоциации

---

# 3. Главные выводы из сравнения

## 1. Философия ≈ религия

- обе ищут **смысл жизни**
- выходят за пределы опыта


## 2. Философия ≈ мифология

- стремятся объяснить **мир целиком**


## 3. Философия ≠ наука (различие)

Наука:

- узкая (изучает часть мира)
- практическая
- не отвечает на вопрос «зачем жить»

Философия:

- общая
- про смысл жизни


## 4. Философия ≈ наука (сходство)

- логика
- доказательства
- понятия


## 5. Философия ≈ искусство

- важен **автор**
- есть стиль и интерпретация

---
# 4. Самое важное (запомнить)

Философия — это:

- **самое общее знание о мире**
- основано на **разуме и логике**
- ищет **смысл жизни**

 Главное отличие:

- от **мифа** → логика вместо фантазии
- от **религии** → разум вместо веры
- от **науки** → шире и про смысл
- от **искусства** → рациональнее

---

# 5. Ультра-краткая формула

- миф → образы
- религия → вера
- наука → факты
- искусство → эмоции
- **философия → смысл + логика**
