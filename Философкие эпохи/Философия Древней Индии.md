# 3. Основные понятия индийской философии

| Понятие | Что это                                         |
| ------- | ----------------------------------------------- |
| Атман   | внутренняя духовная сущность человека           |
| Брахман | абсолютная реальность, основа мира              |
| Сансара | круг перерождений (жизнь–смерть–новая жизнь)    |
| Карма   | закон причин и последствий действий             |
| Дхарма  | долг, правила поведения, порядок                |
| Мокша   | освобождение из сансары  <br>главная цель жизни |
> В упанишадах оформляется идея тождества Брахмана и Атмана как объективного и субъективного начал Универсума
## 1. Брахман

абсолютная реальность, основа мира

## 2. Атман

внутренняя духовная сущность человека

ключевая идея:  
**Брахман = Атман**

## 3. Сансара

круг перерождений (жизнь–смерть–новая жизнь)

## 4. Карма

закон причин и последствий действий

## 5. Дхарма

долг, правила поведения, порядок

## 6. Мокша

освобождение из сансары  
главная цель жизни

# 4. Исторический контекст

Философия возникает в:

VI–V вв. до н.э.

Причины:

- изменения в обществе
- ослабление кастовой системы
- рост роли воинов (кшатриев)

# 5. Два типа школ

## 1. Неортодоксальные (настика)

не признают веды

| Школа             | Основоположник     | Система                                                                                               |
| ----------------- | ------------------ | ----------------------------------------------------------------------------------------------------- |
| Буддизм           | Сиддхартха Гаутама | - мир = страдание<br>- причина страдания = желания<br>- цель = нирвана<br>- нет вечной души (анатман) |
| Джайнизм          | Махавира           | - душа (джива) и материя (аджива)<br>- строгий аскетизм<br>- принцип ахимсы (непричинение вреда)      |
| Локаята (чарвака) | Брихаспати         | - нет души и кармы<br>- мир = 4 элемента<br>- цель жизни = удовольствие                               |

### [[Буддизм]]

Сиддхартха Гаутама

- мир = страдание
- причина страдания = желания
- цель = нирвана
- нет вечной души (анатман)

---

### [[Джайнизм]]

Махавира

- душа (джива) и материя (аджива)
- строгий аскетизм
- принцип ахимсы (непричинение вреда)

---

### Локаята (чарвака)

- нет души и кармы
- мир = 4 элемента
- цель жизни = удовольствие

---

## 2. Ортодоксальные (астика)

признают веды

| Школа            | Основоположник      | Система                                                                                         |
| ---------------- | ------------------- | ----------------------------------------------------------------------------------------------- |
| Санкхья + Йога   | Капила - Патанджали | - два начала:<br>    - Пуруша (дух)<br>    - Пракрити (природа)<br>- цель: освобождение (мокша) |
| Вайшешика + Ньяя | Канада - Гаутама    | - атомы как основа мира<br>- важна логика и доказательство                                      |
| Веданта          | Шанкара             | - мир = проявление Брахмана<br>- цель = соединение с абсолютом                                  |
| Миманса          | Джаймини            | - важны ритуалы и дхарма<br>- опора на веды                                                     |


### Санкхья + Йога

- два начала:
    - Пуруша (дух)
    - Пракрити (природа)
- цель: освобождение (мокша)

---

### Вайшешика + Ньяя

- атомы как основа мира
- важна логика и доказательство

---

### Веданта

- мир = проявление Брахмана
- цель = соединение с абсолютом

---

### Миманса

- важны ритуалы и дхарма
- опора на веды

---

# 6. Общая логика индийской философии

весь мир объясняется через:

- перерождение
- карму
- духовное освобождение

# 7. Главные особенности

- философия + религия не разделены

## 2. Внутренний опыт

- важнее внешнего мира

## 3. Спасение (сотериология)

- главная цель — **освобождение (мокша)**
